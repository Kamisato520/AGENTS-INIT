# AGENTS-INIT

A small Codex skill that adds current OpenAI GPT-6 Astra behavior guidance to the `AGENTS.md` created at the start of a project.

It is designed to work with native Codex `/init`. `/init` creates the repository-specific instructions; `$agent-init` then adds a compact managed section covering initiative, instruction priority, writing style, and proportional verification.

Source: [OpenAI Model Guidance — GPT-6 Astra](https://developers.openai.com/api/docs/guides/latest-model#gpt-6-astra-personality-and-writing-style)

## Install

```bash
npx skills add Kamisato520/AGENTS-INIT
```

For Codex only, globally and without interactive prompts:

```bash
npx skills add Kamisato520/AGENTS-INIT --global --agent codex --skill agent-init --yes --copy
```

## Use

For a new project:

```text
/init
```

Then:

```text
$agent-init
```

AGENT-INIT preserves the project-specific content generated by `/init` and only creates or refreshes the block between:

```text
<!-- AGENT-INIT:START -->
...
<!-- AGENT-INIT:END -->
```

Running `$agent-init` again refreshes that block instead of duplicating it.

## Install by prompt

You can also give Codex this prompt:

```text
Install the agent-init skill from Kamisato520/AGENTS-INIT with the skills CLI for Codex. Verify the installation. For this repository, run native /init first, then use $agent-init to add the OpenAI Astra guidance to AGENTS.md while preserving the repository-specific instructions.
```

## What it adds

The managed section closely follows the OpenAI guidance for GPT-6 Astra in four areas:

- initiative and follow-through;
- instruction following and precedence;
- concise, plain technical communication;
- testing and verification proportional to the change.

The block is intentionally compact because OpenAI notes that Astra is more sensitive to instructions in skills and files such as `AGENTS.md`.
